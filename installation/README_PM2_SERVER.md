# Running Gong Server with PM2

## Start the Server

```bash
pm2 start ~/projects/gong_dev_ops/dev_ops/ecosystem.config.js
```

## Make it Persist After Reboot

```bash
# 1. Generate startup script
pm2 startup

# 2. Run the command PM2 outputs (copy/paste it - looks like):
#    sudo env PATH=$PATH:/usr/bin pm2 startup systemd -u YOUR_USER --hp /home/YOUR_USER
#    (This sudo is ONLY for installing the systemd service - one time setup)

# 3. Save process list
pm2 save
```

> ⚠️ **Important:** Do NOT run regular pm2 commands with sudo (e.g., `sudo pm2 start`). This creates a separate root PM2 daemon that conflicts with your user's PM2. The only sudo command needed is the one generated by `pm2 startup` for installing the systemd service.

## Verify Persistence

```bash
# Check if startup service is enabled (replace YOUR_USER with your username)
systemctl status pm2-YOUR_USER

# Check saved processes
pm2 prettylist | grep name
```

## Common Commands

```bash
pm2 list              # Show running processes
pm2 logs gong_server  # View logs
pm2 restart gong_server
pm2 stop gong_server
```
